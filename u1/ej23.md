# codfish

El "ataque" es simplemente copiar el valor de la variable 
de alto nivel.

```
l = h;
```

No hay restricciones en las reglas.

Podríamos comenzar agregando que las asignaciones no pueden ser de alto nivel a 
bajo nivel.

# joystick

Logro filtrar el valor en h usando "declassify(hatch)". Asignamos h a hatch, y 
filtramos hatch, obteniendo el valor de h.

```
hatch = h;
l = declassify(hatch);
```

El sistema de reglas permite filtrar valores de alto nivel a bajo nivel a través 
de "declassify(hatch), por lo que cualquier valor secreto se puede filtrar.

Eliminar la opción de declasificar, o hacer que a hatch no se le pueda asignar 
un valor de alto nivel parecen opciones válidas.

# graphite

Filtramos el valor de h a través de let.

```
let (x = h) in { l = x; }
```

Como en let no se tiene en cuenta el nivel de la expresión asignada a x, 
podemos asignarle un valor de alto nivel y usarlo en un contexto de bajo nivel.

El sistema de reglas debería asignarle el nivel de la expresión asignada a x 
al bloque c.

# allergy

Filtramos el valor de h usando el flujo "indirecto" de las excepciones.

```
l=false; b=true;
try { 
  if (h) {throw;}
}
catch { while (b) {l=true; b=false;} }
```

El nivel del bloque catch va a ser igual al del try.
Además, podemos usar el bloque while en cualquier contexto (deriva de 
bajo nivel) y su nivel depende de su condición, por lo que podemos filtrar 
información indirectamente sabiendo si hubo o no hubo una excepción.

Para arreglarlo, el nivel del while debe derivar del contexto.

# collect

Utilizamos la invocación de procedimientos para filtrar información.

```
declare proc leak(in a : high, out b : high) {
  b = a;
}

leak(h, l);
```

En la llamada a procedimiento el nivel del valor de retorno es menor o igual 
al requerido por el procedimiento, por lo que podemos pasarle a l como salida 
aunque la función pide 2 valores de alto nivel.

Para arreglarlo, el nivel de la salida debe ser menor o igual al de la variable
en que lo asignamos.

# thousand

Utilizamos las referencias para filtrar el valor de h.

```
declare ref a : high;

ref a = h;
l = deref(a);```

El sistema no tiene en cuenta el nivel de la referencia cuando se le asigna 
un valor, si no el nivel de su contenido. De esta manera, se le puede asignar 
un valor de alto nivel a una referencia de bajo nivel (a es de bajo nivel
porque su nombre no empieza con h, aunque indicamos que su contenido es de 
alto nivel al declararla)

Para arreglarlo, se tiene que tener en cuenta el nivel de la referencia al 
asignarle valoes.

# hospital

Filtramos el dato usando el indexado de arreglos.

```
declare array a : low;

a[h] = true;
a[!h] = false;
l = a[true];
```

No se considera el nivel del valor que indexa al arreglo. Esto nos permite 
asociar el valor de h con la posición que indexa.

Para arreglarlo, el tipo del indexado de un arreglo debería ser menor o igual 
al del arreglo que se quiere indexar.

# reckoning

Realizamos un ataque de timing, observando hasta qué while se llega se 
determina el valor del secreto.

```
while (h1) {
  h1 = !h1;
  while (!h2) {
    h2 = !h2; 
    while (h3) {
      h3 = !h3; 
      while (!h4) { 
        h4 = !h4; 
        while (h5) { 
          h5 = !h5; 
          while (h6) { 
            h6 = !h6;
          }
        }
      }
    }
  }
}

l1 = true;
l2 = false;
l3 = true;
l4 = false;
l5 = true;
l6 = true;
```

El sistema permite usar como guardas variables de alto nivel. Teniendo en 
cuenta el nivel de ejecución se puede obtener el valor de la variable.
Se puede lograr el mismo resultado usando if en vez de while, usando skip; para 
avanzar los pasos de ejecución.

Podemos arreglarlo prohibiendo los loops con guardas que usan variables
de alto nivel y agregando un "padding" de skips en la rama del if con menor 
cantidad de pasos de ejecución.

# adjunct

Realizamos una especie de ataque de timing. Sabiendo cuántos skip se ejecutan
podemos determinar el valor de cada variable.

```
if (h1) { skip; if (!h2) { skip; if (h3) { skip; if (!h4) { skip; if (!h5) { skip; if (h6) { skip; } } } } } }

l1 = true;
l2 = false;
l3 = true;
l4 = false;
l5 = false;
l6 = true;
```

El sistema de tipos no considera como información el tiempo de ejecución/el 
número de pasos del programa.

Podemos arreglarlo haciendo que ambas ramas de un if siempre tengan la misma 
duración.
